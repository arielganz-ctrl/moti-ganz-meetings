# זימון פגישות: מוטי גנץ תכשיטים בע"מ

דף שבו ממלאים פרטי פגישה. הוא פותח וואטסאפ עם הודעה מוכנה למוזמן, ונשאר רק ללחוץ "שליחה".

ההודעה כוללת:
- תאריך, שעת התחלה ושעת סיום
- עם מי הפגישה במשרד
- הכתובת: ז'בוטינסקי 3, רמת גן, בניין יהלום, קומה ג' (ביניים)
- תזכורת להביא תעודה מזהה פיזית (רישיון נהיגה / ת"ז / דרכון) ולהגיע בלי נשק אישי
- בקשה ממי שהגיע בעבר לשלוח מספר ת"ז בתשובה, כדי שיוזמן
- החניון הציבורי "סנטרל פארק", תובל 21, עם קישור ניווט ב-Waze

## איך משתמשים
1. פותחים את הדף בטלפון או במחשב. זה עובד עם WhatsApp Business, וההודעה יוצאת מהמספר העסקי (אם שתי האפליקציות מותקנות בטלפון, בוחרים את Business כשנשאלים).
2. ממלאים שם, טלפון, עם מי הפגישה, תאריך ושעות. שעת הסיום מתמלאת לבד (שעה אחרי ההתחלה) ואפשר לשנות.
3. בודקים את התצוגה המקדימה ולוחצים **שליחה בוואטסאפ**. נפתחת שיחה עם המוזמן וההודעה כבר כתובה, לוחצים שליחה.

   - **במחשב** נפתח WhatsApp Web (web.whatsapp.com) בדפדפן, ולא אפליקציית הוואטסאפ למחשב, כי דרכה האייקונים מגיעים כסימני שאלה. בפעם הראשונה מחברים את WhatsApp Web לוואטסאפ ביזנס: בטלפון, **הגדרות ← מכשירים מקושרים ← קישור מכשיר**, וסורקים את הקוד. כל הזימונים נפתחים באותה לשונית.
   - **בטלפון** הדף פותח את האפליקציה ישירות (`whatsapp://`). אם היא לא נפתחת, מופיע כפתור לדרך החלופית.

   ההודעה גם מועתקת ברקע, כך שאם היא לא מופיעה בשיחה אפשר להדביק אותה.

הפגישות הקרובות נשמרות ברשימה בתחתית הדף (רק בדפדפן שבו שלחתם), עם כפתור "שליחה שוב".

## עריכה
בתחתית `index.html`, בבלוק `CONFIG`:
- `hosts`: השמות שמוצעים בשדה "הפגישה עם" (למשל `['מוטי גנץ', 'דני כהן']`). אפשר תמיד להקליד שם אחר.
- `defaultMinutes`: משך פגישה ברירת מחדל.
- כתובת, קומה וחניה, אם משתנים.

## לא חובה: יומן זימונים בגוגל שיטס
כדי שכל זימון יישמר גם כשורה בגיליון (ולא רק בדפדפן):
1. [sheets.new](https://sheets.new) ← **תוספים ← Apps Script**, מדביקים את `Code.gs` ושומרים.
2. **Deploy ← New deployment ← Web app**, Execute as: **Me**, Who has access: **Anyone** ← Deploy.
3. מעתיקים את הכתובת שנגמרת ב-`/exec` ומדביקים ב-`scriptUrl` ב-`index.html`.

הסקריפט רק מוסיף שורות. הוא לא מחזיר נתונים, כך שאי אפשר לקרוא דרכו מי מוזמן.
